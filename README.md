#### Course Parts Overview

| # | Part Title | Description |
|---|---|---|
| 1 | **Data and Databases** | From managing data in flat files to understanding the role of relational database systems. |
| 2 | **Working with Single-Table Data** | Mastering basic SQL operations to retrieve, filter, and modify data stored in single tables. |
| 3 | **Using Databases from Applications** | From parameterized SQL to create, read, update, and delete flows in a web application. |
| 4 | **Data in Multiple Tables** | Bridging data across multiple tables with SQL joins, subqueries, and set operations. |
| 5 | **Database Design and Modeling** | From domain descriptions to conceptual models, ER diagrams, and design documents. |
| 6 | **Schemas and Constraints** | Turning a conceptual design into a working relational schema that an application can use. |
| 7 | **Summaries and Derived Data** | From row-level queries to summary-level questions with aggregates, grouping, and derived results. |
| 8 | **Transactions, Normalization, and Performance** | Strengthening relational databases through transactions, normalization, and indexing. |
